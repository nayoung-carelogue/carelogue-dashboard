# 케어로그 방문요양 대시보드

Figma `시안` 페이지를 기준으로 만든 React 전시용 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

## 배포 빌드

```bash
npm run build
```

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 빌드하고 GitHub Pages에 자동 배포합니다.

배포 주소: https://nayoung-carelogue.github.io/carelogue-dashboard/

## 구현 범위

- 오늘의 운영: 방문 현황, 직원 활동
- 서비스 개선: 기관 서비스 현황, 수급자별 개선관리, 수급자·보호자 의견
- 수급자 돌봄: 서비스 시작관리, 개인별 계획, 일별 기록, 주간 브리핑, 월간 변화
- 직원 관리: 직원 현황, 근태 기록, 근무·수급자 매칭, 직원 지원, 교육 관리·적용 효과
- 좋은 서비스 관리: 핵심 서비스 지표 A–D, 권리·인권 보호, 증빙자료, 행정 체크리스트, 보고서

## 인터랙션

- 전체 사이드바 메뉴 이동
- 화면 내부 탭 전환
- 방문·직원 행 상세 펼침
- 필터, 검색, 체크리스트
- 서비스 문제와 기록 상세 모달
- 핵심 서비스 지표 A–D 이동
- PC와 태블릿 반응형

최소 글자 크기는 14px로 설정되어 있습니다.
